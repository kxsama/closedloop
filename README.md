# 闭环 ClosedLoop

> **唯一会验收你有没有去做计划的应用。**
>
> 这句是定位宣言，不是已验证结论——证据等级与未验证假设见文末「诚实区」。

市面上不缺提醒。缺的是**验收**。

---

## 它要解决什么

定好 15:00 学英语，到点提醒响了，手一划继续刷抖音——提醒形同虚设。休息时间被短视频吞掉，"再刷五分钟"变成一小时，事后懊悔。

要纠正的行为分两段：

1. **忘了**：想过会去看书，然后就过了很久 → 普通闹钟就能解决，这也是所有时间管理 App 在做的事；
2. **被勾走**：提醒响了，注意力被别的应用截走 → **这是本项目的战场**。

普通提醒死于肌肉记忆式的划掉。而一个**会回查你在哪个应用里**的提醒，划不掉。

## 核心机制

```
定计划 → 到点提醒 → 延迟回查 → 升级催促 → 结算
```

1. **定计划**：选开始时间、时长、**关联应用**（只有待在这些应用里才算有效时间）；
2. **到点提醒**：闹钟级通知（全屏 + 声音 + 震动）；
3. **延迟回查**：不立刻打断你，给你自己切换的机会；之后持续检测前台应用；
4. **升级催促**：情绪递进而非音量递进——担心 → 失望 → 沉默 10 分钟再重来；
5. **结算**：有效时长够了就是完成；不够可选补或作废。**偏离只记录，不算债**。

### 三条不能违背的规则

- **有效时长制**：只有在关联应用里的时间才计时，跑偏就冻结。计划说了算，不是系统说了算；
- **偏离是记录，不是债**：偏离只用来推迟结束时间、进统计、触发熔断。绝不会"偏离 6 分钟就要补 6 分钟"——那是双重惩罚；
- **不变债主**：系统负责让你看见自己在干嘛，不负责催收。

## 与同类应用的区别

| 项目 | 它做什么 | 与本项目的差异 |
|---|---|---|
| 番茄钟类 | 计时 + 锁机 | 管"开始"，不管"有没有在做" |
| 屏幕时间类 | 统计用量 | 只在复盘时让你看见，执行期缺席 |
| 屏蔽类（Reef / Curbox 等） | 分心时拦截 | 方向是反的：**它在"你在分心时拦你"，本项目在"你该干嘛时查你"** |
| **闭环** | 到点验收执行 | 唯一一个**回查你有没有去执行计划**的 |

## 安装

Android：到 [Releases](../../releases) 下载最新 APK → 手机上安装（允许未知来源）→ 首次打开授权「**使用情况访问**」→ 这是检测的地基。

Windows：`app/pc/setup.bat` 装依赖 → `app/pc/run.bat` 启动。

> Android 11+ 需要「使用情况访问」权限；国产 ROM 还需在系统设置里允许自启动，否则后台服务可能被清理（复盘里会出现「未观测」时段，不会被算成偏离）。

## 从源码构建

**Android**（Kotlin，View 体系，无 Compose）：

```bash
cd app/android
# 需要 JDK 17、Android SDK (platform 35 / build-tools 35.0.0)
export ANDROID_HOME=/path/to/Android/Sdk
gradle assembleDebug
```

产物在 `app/build/outputs/apk/debug/`。

**Windows**（Python 3.13 + Tkinter/CustomTkinter）：见 `app/pc/README.md`。

## 隐私

**全部数据留在本机。无服务器、无账号、无网络上报。**

使用情况数据只写入本机存储（Android 的 SharedPreferences / Windows 的 `app/pc/data/`）。开源的意义之一就是让这句话可以被审计，而不是只能被相信。

## 诚实区

### 未验证的假设

本项目的设计建立在几个**尚未被实验验证**的推断上，任一个不成立整条链都要改。这里原样列出，不藏：

| 假设 | 状态 |
|---|---|
| 延迟回查比即时提醒更有效 | **未验证**（最核心的一个） |
| 人格化催促比系统通知留存更高 | 未验证 |
| 失望语气比愤怒更有效 | 未验证 |
| 有效时长制符合直觉 | 未验证 |

### 已知局限

- **"前台 ≠ 投入"**：应用挂在前台但人在发呆（尤其亮屏），现有启发式抓不住。超长无中断时段只会被标记「待确认」；
- **检测精度**：`UsageEvents` 有数秒到数十秒延迟，不是秒级精确；
- **观测完整性**：服务被杀会出现「未观测」空洞，这些时段不参与任何结算；
- **Android 高版本差异**：Live Updates 需要 Android 16+，旧版本自动降级为普通常驻通知。
