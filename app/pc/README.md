# 闭环 · PC 版 v0.1

按 `SPEC-行为闭环应用-v0.2.1` 实现的 Windows 桌面版：计划 → 到点提醒 → 每分钟检测前台进程 → 有效时长结算 → 升级催促 → 复盘。

## 启动

双击 `run.bat`（首次如提示缺 venv，先跑一次 `setup.bat`）。

## 三分钟测试剧本

1. 点「＋ 新建计划」：名称随意，开始时间填 2 分钟后，目标 10 分钟，白名单进程填 `notepad.exe`；
2. 到点会弹出 L1 提醒（带音效），右上角出现常驻小窗（绿色「计时中」）；
3. 打开记事本放着 → 有效时长正常累计；
4. 切到浏览器/别的窗口超过 1 分钟 → 小窗变黄色「偏离中」，语气从担心开始；
5. 继续不理 5 分钟 → 变红色「持续偏离」，语气变失望（L3）；
6. 点「这就回去」→ 小窗安静 2 分钟（但计时规则不变）；
7. 回到记事本 → 恢复计时，颜色变回绿色；
8. 有效时长满 10 分钟 → 弹出完成庆祝；或者点「提前结束」体验原因快选与「未完成」记账；
9. 主窗口下方「当日复盘」查看账本。

## 规则（与 spec 对齐）

- **有效时长制**：只有前台在白名单内才计时，偏离即冻结；
- **去抖宽限**：偏离不足 60 秒不计（切出去看一眼没事）；
- **升级阶梯**：到点 L1 → 回查后偏离 L2 → 连续偏离 5 分钟 L3 → 连续 10 分钟进入沉默（晚间复盘一起算）；
- **熔断**：累计偏离 ≥ 目标时长时问「还要吗」，不自动记未完成；
- **提前结束**：一次有理由的退出，差多少记多少「未完成」；
- **锁屏/休眠**：记「未观测」，不算偏离；服务中断空洞同样显式标注。

参数（宽限、升级阈值、熔断比例）都在 `engine.py` 顶部常量区，可直接改。

## 数据

`data/` 目录：`plans.json`（计划）、`sessions.json`（进行中会话，崩溃可续）、`ledger.json`（每日账本）、`events.jsonl`（全量事件流）。

## 已知边界

- PC 版没有 Android 的 Live Updates，常驻小窗是等价物；
- 检测是**进程级**的：浏览器算一个进程，分不清你在刷网页还是看网课（白名单可用窗口标题关键词补充）；
- 前台 ≠ 投入：亮屏发呆抓不到，这是 spec 里承认的已知局限。
